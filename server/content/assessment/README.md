# بنك أسئلة Link Me

1000 سؤال أصلي للقواعد والمفردات والمواقف اليومية وفهم النص؛ التوزيع المقصود A1:180، A2:180، B1:180، B2:180، C1:160، C2:120. ملف bank.json يحتوي الإجابات والشروح ويُستورد على السيرفر فقط، بينما يحمل المتصفح أسئلة المرحلة الحالية.

استُخدمت أوصاف المستويات العامة لمجلس أوروبا كاتجاه للصعوبة: https://www.coe.int/en/web/common-european-framework-reference-languages/table-1-cefr-3.3-common-reference-levels-global-scale . وشرح British Council لطبيعة المؤشر التقريبي: https://learnenglish.britishcouncil.org/level/understand-your-english-level . لا تُنسخ أسئلة أي امتحان منشور.

القياس هنا تقديري وتعليمي ومبني على أسئلة مكتوبة. ليس اختبارًا معتمدًا أو مُعايرًا تجريبيًا، ولا يقيس التحدث أو الاستماع. اجتياز مرحلة C2 يعني أداءً جيدًا في هذه العينة المكتوبة لا شهادة كفاءة شاملة. معيار 75% لتدرج المراحل قرار منتج وليس حدًا رسميًا لمستويات CEFR.

scripts/build-assessment-bank.py يولد دفعات ويحتفظ بالدفعات المراجعة ثم يجمع بنكًا كاملًا بعد فحص العدد، تفرّد النص والسياق، صلاحية الخيارات، والشروح العربية. تمت مراجعة الإجابات والالتباس آليًا بموديل مستقل؛ ينصح المالك بمراجعة تربوية بشرية وبتحسين الصعوبة بناءً على إجابات الطلاب الفعلية قبل استعمال النتائج لأغراض عالية الأهمية. quality.json يلخص العد والفحص ولا يثبت اعتمادًا لغويًا.
